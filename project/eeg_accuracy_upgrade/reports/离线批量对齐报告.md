# 离线无标签批量对齐实验

**这是一个单独的评估条件：使用了测试人员的未标注 EEG 波形估计对齐参数，没有使用他们的左右手标签训练或选参数。因此不能当作完全不接触目标数据的单试次泛化成绩。**

| 数据集 | 无标签批量对齐准确率 |
|---|---:|
| PhysioNet | 68.92% |
| BNCI2014_001 | 71.49% |

方法：逐人、逐频带估计平均协方差，以逆平方根做空间白化，再计算矩阵对数特征，使用收缩 LDA 或 RBF SVM 分类。九/二十二通道与分类器只由验证人员选定。采用与主实验完全相同的试次、人员隔离和伪迹规则。

选择此模式是因为当前需求是完整公开文件的离线实验。它需要同一个人的一批试次，不能用一个窗口估计可靠的个人参考；接口至少要求每人五次试验。改变输入批次可能改变预测。报告中的成绩采用完整测试人员批次，不应推断为少数窗口或实时准确率。

双击 run_aligned_demo.cmd 演示第一折。Python 调用 model_api.predict_aligned(X, subject_ids, model_path)，其中 X 为 (试次数,22,1000)，subject_ids 与试次一一对应。标签 y 不传入预测函数。

灵感来源：He & Wu, Transfer Learning for Brain-Computer Interfaces: A Euclidean Space Data Alignment Approach, https://arxiv.org/abs/1808.05464 。这里是逐频带正则化协方差白化的变体，并非原论文完整复现。

本数据以前已经用于测试，当前结果仍是重复基准比较，不是新的盲测。

# 提高准确率：离线使用说明

这里比较不同算法并保存了训练好的模型。全部使用已下载的公开数据，不需要脑电设备。原先的模型和报告仍保留。

## 最简单的使用方法

1. 双击 `run_demo.cmd`：加载验证集选定的模型，预测 PhysioNet 第一折的公开测试数据，终端会输出 `LEFT / RIGHT` 和 `TURN_LEFT / TURN_RIGHT`。
2. 双击 `run_neural_demo.cmd`：明确使用通过反向传播+Adam训练的多层感知机神经网络，预测同一批测试数据。
3. 查看 `reports/算法升级报告.md`，比较整套测试结果；每次运行演示的全部预测保存在 `reports/latest_predictions_*.csv`。

另有 `run_aligned_demo.cmd`：对完整文件按人做无标签批量对齐后预测。它使用了这批待测 EEG 波形估计参考，但不使用标签。其结果见 `reports/离线批量对齐报告.md`，属于单独的离线自适应条件，不能当作普通单窗口准确率。

演示只做加载和预测，不会重新训练。第一折的成绩与所有折汇总成绩不一定相同。第一折是预先固定的演示选择，不是挑测试分数最高的模型。

## 模型和数据

- `models/PhysioNet_selected_fold00.joblib`：PhysioNet 第一折中，仅用验证集选定的方案。
- `models/PhysioNet_neural_fold00.joblib`：同一折中，仅用验证集选定的神经网络。
- `models/BNCI2014_001_selected_fold00.joblib`：BCI IV 2a 第一折的验证选择方案。
- 其他编号是其他外层测试折；每个文件内的 `split` 保存其训练、验证、测试人员。不能用一个模型预测它的训练人员后把准确率称为独立测试成绩。
- `data/PhysioNet/first_fold/train.npz`、`validation.npz`、`test.npz`：第一折按人隔离的三组数据；BCI IV 2a 的结构相同。
- `data/PhysioNet_22channels.npz` 和 `data/BNCI2014_001_22channels.npz`：完整的二十二通道公开试次；试次、标签与之前的九通道实验逐条相同。
- 原始 MAT/EDF 文件继续复用同级 `external_eeg_tests` 项目，不再重复下载。演示预测所需数据和辅助代码已包含在本目录，直接预测不需要读取原始库。只有重新从原始文件准备数据或重跑旧基线比较时，才需要保留同级原项目。

模型输入统一为 `(批量试次数,22,1000)` 或单次 `(22,1000)`，250 Hz，4 秒，单位微伏。二十二通道依次为：

```text
Fz, FC3, FC1, FCz, FC2, FC4, C5, C3, C1, Cz, C2,
C4, C6, CP3, CP1, CPz, CP2, CP4, P1, Pz, P2, POz
```

有些折选择九通道特征，但统一接口仍接收上述二十二通道，由程序内部选取。不要把之前的三/九通道文件直接交给这个新接口。

NPZ 的 `X` 是脑电波形；`y` 为 0=左手、1=右手；`channels` 保存通道顺序；`fs` 是采样率；`unit` 是单位；其余包含人员、会话、试次编号和原始伪迹标记。

## 在 Python 程序里调用

```python
from pathlib import Path
import numpy as np
from model_api import predict_eeg

root = Path(__file__).resolve().parent
data = np.load(root / 'data/PhysioNet/first_fold/test.npz', allow_pickle=False)

labels = predict_eeg(
    data['X'][:10],
    root / 'models/PhysioNet_selected_fold00.joblib',
    channels=data['channels'],
)
print(labels)  # 0=左手，1=右手
```

接口内部负责参考处理、滤波和特征提取，输入原始窗口即可。输出是左右手类别，没有声称为已校准置信度的数值。模型文件只从本项目或可信来源加载。

## 在终端选择数据和模型

下面的命令在项目目录执行。当前电脑的 `.cmd` 文件会使用已安装的独立 Python 环境；重建环境时可安装 Python 3.12 后运行 `py -3.12 -m venv .venv`，再执行 `.venv\Scripts\python.exe -m pip install -r requirements.txt`。

```powershell
# 下面示例适用于已经重建的项目内 .venv
.\.venv\Scripts\python.exe demo_predict.py
.\.venv\Scripts\python.exe demo_predict.py --neural
.\.venv\Scripts\python.exe demo_predict.py --aligned
.\.venv\Scripts\python.exe demo_predict.py --dataset BNCI2014_001
.\.venv\Scripts\python.exe demo_predict.py --dataset PhysioNet --fold 1

# 预测自己的离线 NPY/NPZ 文件：NPZ 至少包含 X，推荐包含 channels、fs、unit
.\.venv\Scripts\python.exe demo_predict.py --input input.npz --model models/PhysioNet_selected_fold00.joblib

# 重新做全部算法比较，会更新本目录派生模型和报告，耗时较长
.\.venv\Scripts\python.exe train_compare.py
.\.venv\Scripts\python.exe train_alignment.py
```

## 怎样解读这次实验

神经网络通过反向传播训练，但不保证比传统算法更准；训练准确率高也不等于跨人测试准确率高。最终每折的方案只根据独立验证人员的成绩选择，测试人员不参与停止轮次和算法选择。

新方案同时比较九路与二十二路 EEG。原始输入增加电极也可能带来提升，因此报告保留九通道控制组，避免把额外空间信息全部归功于算法。

以前已经看过这些公开测试数据的成绩，所以本次属于重复基准比较，不能当作全新盲测，也不保证对新采集数据有同样准确率。这里只做左右手二分类，没有检测静息或什么时候应该下达游戏指令。终端输出 TURN_LEFT/RIGHT 是离线演示文本，尚未自动连接游戏。

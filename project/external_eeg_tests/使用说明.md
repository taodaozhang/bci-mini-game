# 两套新增左右手 EEG 数据与测试

本目录独立保存新数据、代码、冻结的旧模型、新训练的模型和测试报告。之前桌面项目里的模型不替换。

## 先查看结果

双击 `show_results.cmd` 可以查看已完成的测试成绩，不会重新下载或训练。

详细中文报告：`reports/泛化测试报告.md`；结果图：`reports/external_results.png`；机器可读结果：`reports/results.json`。每个实验还有逐人和逐试次 CSV。

## 数据文件

- `data/raw/physionet/`：PhysioNet 全部 109 人的 R04、R08、R12 EDF+ 文件，只包含这三种左右手运动想象运行。每个原始文件保留全部 64 路 EEG 和嵌入的事件注释。其他真实运动、双手/双脚的运行没有下载。
- `data/raw/bnci001/`：BCI Competition IV 2a 的全部 18 个官方 MAT 文件，原始 22 路 EEG、3 路 EOG 和四类任务均保留。测试只提取左右手，其他类别不参与模型。
- `data/sources.json`：真实来源 URL、文件大小、SHA-256、许可。
- `data/prepared/数据名/all_epochs.npz`：统一的 9 路运动皮层 EEG、250 Hz、4 秒窗口，单位微伏；形状 `(试次数,9,1000)`。通道依次为 `FC3, FCz, FC4, C3, Cz, C4, CP3, CPz, CP4`。这里仍保留各数据源的原始参考；新模型内部再做九通道平均参考。
- NPZ 中 `y` 为 0=左手想象、1=右手想象；另有 `subject`、`session`、`trial_id`、`artifact`、`channels`、`fs`、`unit`。`artifact` 为 1 表示官方专家标记有伪迹，0 表示官方标记无伪迹，-1 表示该源没有这种标记。
- `quality_audit.json`：排除事件的客观原因。比如想象事件不足 4 秒时，不拉长、不补造波形。
- `subject_folds.json`：每一轮训练/验证/测试的人员清单，三组没有同一个人。
- `first_fold_splits/train.npz`、`validation.npz`、`test.npz`：第一轮的三组数据。其他轮通过完整 NPZ 和人员清单重建，避免重复存很多份大文件。

## 三种测试的区别

1. **冻结旧模型外部测试**：旧的 3 路双极 EEG 模型直接读取新数据的 C3/Cz/C4。保留原模型参数，不做目标数据调参。由于参考导联不匹配，这是探索性压力测试，不能将其成绩下降全部归因于人的泛化。
2. **新数据中的跨人测试**：采用九路统一处理的模型。PhysioNet 进行 5 轮按人划分，2a 进行 9 轮留人测试；训练、选参数、最终测试都隔离人员，每个人最终只测试一次。
3. **两套新数据互相迁移**：固定 FBCSP+收缩 LDA，一套训练、另一套直接测试。没有用目标数据调参，检验换采集项目后的迁移表现。

每轮按人测试保存一个模型，文件名中的 `fold00` 表示第一轮。它只对该轮指定的测试人员有独立测试证据，不等于在整个数据集上训练的最终部署模型。

## 运行

本机 `.cmd` 默认使用 Documents/Codex 下本任务的独立环境，也优先支持目录内的 `.venv`。移动项目或删除任务目录后，请安装 Python 3.12 并重建环境：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 只查看已完成的成绩
.\.venv\Scripts\python.exe show_results.py

# 对已准备好的数据重跑全部实验（会更新本目录派生模型和报告）
.\.venv\Scripts\python.exe test_external_eeg.py --evaluate

# 从原始数据重新准备并测试
.\.venv\Scripts\python.exe test_external_eeg.py

# 下载缺失的原始文件，已有文件复用
.\.venv\Scripts\python.exe download_external.py --workers 4
```

新模型的调用接口：

```python
from test_external_eeg import predict_saved

# eeg 为 (9,1000) 或 (批量,9,1000)，通道和单位必须与上文一致。
# 输入原始窗口；函数会做九通道平均参考、滤波及特征提取。
labels = predict_saved(eeg, 'models/PhysioNet_unseen_subject_fold00.joblib')
```

九路输入的 `predict_saved` 仅用于本目录的新模型；冻结的旧模型须使用 `eeg_baseline.predict_eeg` 和三路输入。只加载自己生成或可信来源的 joblib 文件。

这些都是离线左右手二分类实验，尚未建立静息/无指令识别、在线拒绝输出或真实游戏性能测试。公开数据成绩不能直接当作本人设备的成绩。

# 已完成的数据下载和模型训练

这次已实际下载、划分、训练和测试。数据来自你指定网站中的 BNCI 2014-004（BCI Competition IV 2b），专门用于想象左手/右手。原来的“数据处理器.py”只有一位受试者的数据读取和画图；新脚本独立运行。

## 在这台电脑上运行

双击 `demo_predict.cmd`：加载已经训练好的模型，对独立测试集进行预测并显示准确率。

双击 `retrain.cmd`：使用现有原始数据重新划分、训练全部模型。不会再次下载已有文件；会更新本项目的数据划分、模型和报告。

这两个启动文件使用本任务安装的独立 Python 环境。如果移动或删除 Documents/Codex 下的本任务目录，请按下面方式重建环境。

## 文件位置

| 路径 | 内容 |
|---|---|
| `train_left_right_eeg.py` | 完整下载、划分、特征提取、模型训练、测试及预测接口 |
| `demo_predict.py` | 加载模型的演示 |
| `data/raw/` | 9 人的 18 个官方 MAT 原始文件 |
| `data/splits/train.npz` | 第一组：会话 1–3，共 3,680 次 |
| `data/splits/validation.npz` | 第二组：会话 4，共 1,400 次 |
| `data/splits/test.npz` | 第三组：会话 5，共 1,440 次 |
| `data/splits/trial_manifest.csv` | 每个试次的来源、标签、会话、伪迹标记和分组 |
| `data/sources.json` | 原始下载地址、文件长度和 SHA-256 |
| `models/left_right_global.joblib` | 已训练好的通用模型 |
| `models/left_right_B01.joblib` 等 | 9 位公开数据受试者各自的模型 |
| `reports/训练报告.md` | 各模型的真实测试结果及适用范围 |
| `reports/metrics.json` | 详细准确率、混淆矩阵、Kappa 等 |
| `reports/test_results.png` | 测试结果图 |

NPZ 用 `np.load(path, allow_pickle=False)` 打开。`X` 是原始微伏 EEG，形状为 `(试次数, 3, 1000)`；`y` 是标签，0=左手，1=右手；另含 `subject`、`session`、`trial_id`、`artifact`、`fs`、`channels` 和 `unit`。`artifact=1` 表示原始专家标记有伪迹。完整试次和伪迹标记都保留；训练使用 3,026 个无伪迹试次，选参数使用 1,125 个无伪迹验证试次，测试主结果保留全部 1,440 个试次。

划分按整次采集会话隔离，不拆分或随机混入重叠窗口。三组中受试者相同，所以测试结果是跨会话结果，不是对新用户的泛化结果。

## 已得到的结果

通用模型：验证集平衡准确率 78.24%，独立测试集准确率 **76.25%**；无伪迹测试子集准确率 76.61%。测试集左右手各 720 次，随机猜测基线为 50%。个人模型加权测试准确率 78.12%；个人差异见报告，不按测试集成绩挑选一个人的模型给其他人用。

最终通用模型是滤波器组相对频带功率 + 标准化 + RBF SVM；候选还包含 FBCSP 和 LDA/线性 SVM。只由验证集选择参数，训练参数只拟合训练集，测试集不参加训练。小数据可以训练这种传统机器学习模型，不需要先训练大型神经网络。

## 在游戏代码中调用

```python
from train_left_right_eeg import predict_eeg

# eeg_window: numpy 数组，形状 (3, 1000)
# 250 Hz，4 秒，通道严格为 C3、Cz、C4，单位微伏。
label = int(predict_eeg(eeg_window)[0])
# label == 0: 左手；label == 1: 右手
```

预测时会自动执行与训练一致的因果滤波和特征提取。输入是原始窗口，不要自行重复同样的数字带通滤波。模型每次使用完整 4 秒数据，前 0.5 秒仅用于滤波过渡，不能把它当作毫秒级即时判别。

公开数据使用三路双极 EEG；实际设备必须核对电极位置、导联/参考方式、采样率和单位。新用户应采集自己的带标签数据完成校准。本模型只有左右手两个类别，没有“静息/无指令”类别，不能单靠它判定什么时候应该发出游戏指令。

只加载本项目自己生成或可信来源的 joblib 文件。

安装 Python 3.12，然后在项目目录的终端运行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe demo_predict.py
.\.venv\Scripts\python.exe train_left_right_eeg.py
```

```powershell

.\.venv\Scripts\python.exe train_left_right_eeg.py --predict data/splits/test.npz

# 重新训练单一受试者，输出到独立目录以保留原模型
.\.venv\Scripts\python.exe train_left_right_eeg.py --subjects 1 --root personal_B01
```
